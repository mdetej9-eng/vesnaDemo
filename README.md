# Салон «Весна» — сайт-визитка

Одностраничный сайт-визитка для салона парикмахерской «Весна» (г. Ставрополь, ул. Пирогова, 38г).

## Стиль

Editorial light: кремовый фон, коралловый акцент, шрифты Unbounded + Manrope. Сплит-герой, нумерованные списки услуг, галерея с лайтбоксом, крупный контактный блок.

## Что внутри

- **Плашка «Демо-концепт»** в углу — сайт сделан заранее для презентации
- **Сплит-герой** с чипами (график 8:00–20:00, адрес, телефон)
- **Услуги** — нумерованные строки 01–03 с тегами
- **О салоне** с фото входа и статистикой
- **Наши работы** — галерея 8 фото с лайтбоксом
- **Контакты**: большой тел.-блок, адрес, режим работы, 2ГИС

## Технологии

Чистый HTML + CSS + JavaScript, без сборщиков и зависимостей.
